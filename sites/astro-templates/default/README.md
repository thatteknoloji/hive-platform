# HIVE Astro Site

Bu şablon HIVE Astro Site Factory tarafından kopyalanır. Proje oluşturulduğunda `README.md` proje bilgileriyle güncellenir.

```bash
npm install
npm run dev
npm run build
```

Cloudflare Pages tek tık deploy: HIVE panel → Astro Site Factory → Build & Export.  
Detay: `docs/astro-factory-cloudflare.md`
